# Portfolio — Romain Desreumaux

Bienvenue sur le dépôt de mon portfolio personnel !

Ce projet a pour objectif de présenter mon profil, mes compétences en développement, les outils que j'utilise, mon parcours et les projets sur lesquels je travaille.

## À propos

Je m'intéresse au développement et à la conception d'applications. À travers ce portfolio, je souhaite présenter mon évolution, mettre en valeur mes réalisations et continuer à développer mes compétences techniques.

## Fonctionnalités

- Présentation de mon profil
- Sections dédiées aux compétences et aux outils
- Présentation de mon parcours et de mes expériences
- Galerie de projets
- Section de contact
- Design sombre avec des accents violets et bleus
- Fond animé avec des effets lumineux
- Animations au défilement
- Interface adaptée aux ordinateurs, tablettes et mobiles
- Navigation responsive

## Technologies utilisées

- **HTML5** — Structure des pages
- **CSS3** — Mise en page, design responsive et animations
- **JavaScript** — Interactions et effets dynamiques
- **Git** — Gestion de versions
- **GitHub** — Hébergement du code source

## Installation

Pour consulter le projet localement :

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/romdx59/portfolio-romaind.git
   ```

2. Accédez au dossier :

   ```bash
   cd portfolio-romaind
   ```

3. Ouvrez le fichier `index.html` dans votre navigateur.

Aucune installation de dépendances n'est nécessaire pour cette version HTML, CSS et JavaScript.

## Déploiement

Le portfolio peut être hébergé sur une plateforme de déploiement statique, comme GitHub Pages ou Vercel.
